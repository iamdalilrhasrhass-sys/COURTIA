## 9. Définitions des métriques (à ne pas confondre)

| Indicateur | Définition |
|---|---|
| CTR SERP | clics / impressions (Search Console) |
| CTA Rate | clics CTA / sessions organiques mesurées |
| Demo Rate | demandes de démo / sessions organiques mesurées |
| Trial Rate | essais créés / sessions organiques mesurées |
| Activation Rate | essais activés / essais créés |
| Customer Rate | clients / sessions organiques mesurées |

Un CTR SERP élevé ne démontre aucune supériorité de conversion : ce sont deux indicateurs distincts.

## Limites de lecture

- `site_visit` compte les visites mesurées par le script first-party, pas les sessions côté Google.
- Un même visiteur peut produire plusieurs événements : ce sont des volumes, pas des personnes.
- Les adresses de test (`@example.invalid`) sont exclues du décompte des demandes réelles.
- Les données Search Console portent sur le domaine entier, ancien plan `/fr` et `/ch` inclus.
- Aucune donnée personnelle (nom, e-mail, téléphone) ne figure dans ce rapport.

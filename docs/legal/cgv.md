# CGV COURTIA

Base operationnelle a faire valider juridiquement.

Les abonnements COURTIA sont factures via Stripe lorsque la configuration est active. Les prix publics peuvent varier selon l'offre souscrite.

Le client peut resilier selon les conditions contractuelles applicables. Aucune donnee carte bancaire n'est stockee par COURTIA.

La responsabilite COURTIA est limitee aux montants payes sur la periode concernee, sauf disposition legale imperative contraire.

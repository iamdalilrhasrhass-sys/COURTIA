# DPA COURTIA

Base operationnelle a faire valider juridiquement.

Le cabinet est responsable de traitement. COURTIA est sous-traitant pour les traitements necessaires au service:

- CRM client
- contrats
- taches
- documents DDA
- notifications
- integrations configurees
- support
- observabilite

Les demandes RGPD doivent etre traitees selon le perimetre du cabinet et les obligations legales applicables.

# Growth Playbook — COURTIA

## Objectif

Lancer une acquisition B2B ciblée courtiers France en mode RGPD-first.

## Pile growth du repo

- `growth/leads/` : pipeline leads, scoring, exports
- `growth/outreach/` : emails, LinkedIn, appels, objections
- `marketing/videos/` : assets vidéo social/ads
- landing conversion : `/`, `/tarifs`, `/demo`, `/contact`

## Cadence recommandée

1. qualifier de nouveaux leads (source publique documentée)
2. enrichir score + priorité A/B/C
3. lancer séquence email + LinkedIn manuelle
4. suivre statuts: `a_contacter`, `contacte`, `demo_prevue`, `gagne`, `perdu`
5. boucler vers `/admin/growth-leads`

## ICP prioritaire

- courtiers indépendants et cabinets 1-20 collaborateurs
- spécialités IARD / santé / prévoyance / pro
- présence digitale active + email pro public

## KPIs

- taux de réponse
- taux de prise de démo
- taux de conversion démo → gagné
- cycle moyen premier contact → démo

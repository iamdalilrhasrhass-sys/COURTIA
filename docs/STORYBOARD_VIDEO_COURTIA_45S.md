## Script voix off

| Temps | Voix off | À l'écran | Plan |
|-------|----------|-----------|------|
| 0-5s | *"Trop de clients. Trop de contrats. Trop d'échéances."* | Fond sombre. Texte seul qui apparaît. | Texte centré |

| 22-28s | *"Suivez vos contrats, devis et documents sans perdre le fil."* | Enchaînement rapide : Contrats → Devis → Documents. | Montage cut |

| 35-42s | *"Chaque matin, Morning Brief ARK vous indique quoi traiter, pourquoi, et comment agir."* | Opportunités détectées. Relances classées par urgence. | Split screen : relances + opportunités |
| 42-45s | *"COURTIA — Le cockpit intelligent des courtiers en assurance."* | Logo COURTIA. Texte : "courtiark.fr — Demander une démo". | Plan final logo |

## Fiche technique

| Élément | Spécification |
|---------|---------------|
| Durée | 45 secondes |
| Format | 16:9 horizontal (1920×1080) |
| Musique | Instrumentale sobre, montée progressive, pas agressive |
| Palette | Aurora dark (#02040c fond, #8B5CF6 accents, #5B4DF5 CTA, halos cyan/violet) |
| Typographie | Sans-serif premium (Inter, SF Pro Display, ou équivalent) |
| Effets | Transitions douces, pas de flashs. Halos subtils. Lueur violette sur ARK |
| Voix off | Française, masculine ou féminine, ton sérieux et confiant |
| Sous-titres | Optionnels, pour réseaux sociaux sans son |

---

## Préparation avant tournage

1. Vérifier que toutes les pages sont propres (Aurora dark, données démo cohérentes).
2. Vérifier l'absence de "Capitia", "ARK Financement", compagnies réelles, prix incohérents.
3. Préparer la résolution 1920×1080 sur navigateur desktop.
4. Désactiver les barres d'outils navigateur pour des captures propres.
5. Utiliser un outil de capture d'écran fluide (Screen Studio, CleanShot X, OBS).

# Sources publiques (cadre légal)

Sources potentielles documentées pour prospection B2B courtiers:

1. ORIAS (registre public) — vérification manuelle ou export légal autorisé.
2. Annuaires professionnels publics (conditions d'utilisation à respecter).
3. Sites web officiels de cabinets (pages contact, mentions légales, équipe).
4. Open data publics pertinents (si disponibles selon période).
5. Répertoires institutionnels (CCI, organisations professionnelles).

## Règles d'usage

- aucun contournement anti-bot
- aucun bypass captcha/login
- respect de robots.txt
- conservation de la preuve source (`source_url`, `source_name`, `source_date`)
- collecte minimale strictement liée à l'activité professionnelle

## Limitations dans ce dépôt

Les exports fournis dans cette version sont des **samples** marqués `SAMPLE_DO_NOT_CONTACT`.
Ils servent à valider le pipeline technique et RGPD avant import de leads réels.
